СЕДМИЧНО МЕНЮ – уеб приложение за инсталиране (PWA)

1. Направи безплатен акаунт в github.com.
2. Създай ново хранилище (New repository), например "menu", с отметка Public.
3. Натисни "uploading an existing file" и качи ВСИЧКИ файлове и папки от този архив
   (index.html, manifest.webmanifest, sw.js, папките icons и fonts).
4. Settings → Pages → Branch: main, папка / (root) → Save.
5. След 1-2 минути адресът е: https://ТВОЕТО-ИМЕ.github.io/menu/
6. Отвори адреса в Chrome на телефона → меню ⋮ → "Инсталиране на приложението".

След първото отваряне приложението работи и без интернет.
Данните се пазят само на телефона. Ползвай "Запази архив" в раздел Планиране.
