# Седмично меню

## Кой файл за какво е

| Файл | Какво има в него | Кога да го пипаш |
|---|---|---|
| `index.html` | Скелетът на страницата: бутони, полета, раздели | Нов бутон, ново поле, друг текст в заглавие |
| `css/styles.css` | Цветове, шрифтове, размери | Друг цвят, по-голям текст |
| `js/config.js` | Дни, видове хранене | Ново хранене, например „Следобедна закуска“ |
| `js/utils.js` | Малки помощни функции | Почти никога |
| `js/storage.js` | Записът на данните в телефона | Почти никога |
| `js/render.js` | Как изглеждат менюто, списъкът с рецепти и планирането | Промяна в показването на списъците |
| `js/recipe-view.js` | Как изглежда отворената рецепта | Промяна в показването на рецептата |
| `js/recipe-editor.js` | Формата за въвеждане на рецепта | Ново поле в рецептата |
| `js/parse.js` | Разпознаване на количества и стъпки | Нова мерна единица |
| `js/backup.js` | Архив във файл | Почти никога |
| `js/sync.js` | Синхронизация с GitHub | Почти никога |
| `js/app.js` | Какво правят бутоните, стартиране | Нов бутон |
| `sw.js` | Офлайн режим | Ако добавиш нов файл, впиши го в списъка FILES |

Файловете в `js/` се зареждат в реда, в който са изброени най-долу в `index.html`. `app.js` трябва да е последен.

## Как да видиш промяната

След като качиш променен файл в GitHub, изчакай 1–2 минути и отвори приложението с интернет.
Ако промяната не се вижда, затвори го напълно и го отвори отново.

## Чести промени

**Друг основен цвят:** в `css/styles.css`, най-горе, смени `--herb: #1F3A2E;` (за тъмната тема и реда `--herb: #9FD3B2;`).

**Ново хранене:** в `js/config.js` добави ред в MEALS, например `["snack", "Следобедна закуска"],`.

**Нова мерна единица:** в `js/parse.js` добави я в списъка UNITS, например `"чаш[аи]",`.
